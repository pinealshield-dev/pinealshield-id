# Pineal ID

Pineal ID is the official mobile client for the Pineal Shield trust infrastructure.

It provides secure, read-only verification of authenticity for certified assets using QR and NFC,
acting as a verification surface — not a decision authority.

## Scope

- Mobile verification client (iOS / Android)
- No private keys stored
- No business rules enforced client-side
- All authenticity decisions are made server-side

## Architecture Principles

- Zero-trust client
- Verifiable responses
- No marketing logic
- Evidence-oriented UX

## Status

Work in progress. Not intended for production use yet.
